# Lumen AI School

Theme: warm editorial white, cobalt blue and coral; Manrope + Playfair Display.

Run `npm install` then `npm run dev`. Build with `npm run build`. Vercel: Vite, build command `npm run build`, output `dist`.

Four routes: home, searchable program catalog, course detail with expandable daily lessons, faculty. Signup is a frontend demo. Prices are illustrative, and faculty credentials/affiliations must be verified before launch. Images use Unsplash URLs.
